# Programming & Technical

This section covers the coding fundamentals and practical security challenges relevant to security engineering roles. Security engineers need programming skills for automation, tool development, log analysis, and understanding application-level vulnerabilities.

## Core Topics

- **[Coding Fundamentals](fundamentals.md)** - Data structures for security engineers, algorithms and complexity (Big O), regular expressions, Python essentials, scripting for security automation
- **[Security Challenges](challenges.md)** - Hands-on coding exercises: cipher implementation, log parsing and analysis, port scanner, web scraper, password brute-forcer, malware signature scanner, metadata extraction, deleted file recovery

## Key Learning Objectives

After studying this section, you should understand:

- Core data structures and when to use them in security tooling
- Algorithm complexity and its impact on security operations at scale
- Regular expressions for log parsing and pattern matching
- Python fundamentals for security scripting and automation
- How to build basic security tools (scanners, parsers, analysers)
- Practical coding patterns used in penetration testing and forensics

!!! info "Prerequisites"
    Basic programming experience in any language is helpful but not required. For Python fundamentals, refer to the [Python Official Tutorial](https://docs.python.org/3/tutorial/) and [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/).
