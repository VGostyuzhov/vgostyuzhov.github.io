# Compliance & Governance

This section covers regulatory frameworks, security governance structures, and the operational practices that tie security controls to business and legal requirements. Compliance demonstrates that security measures meet defined standards; governance ensures those measures are maintained.

## Core Topics

- **[Regulatory Frameworks](frameworks.md)** - SOC 2 (Type I vs Type II), ISO 27001/27002, PCI DSS, GDPR, HIPAA, NIST Cybersecurity Framework, FedRAMP, framework comparison matrix
- **[Security Governance](governance.md)** - Security policies and standards, organizational structure, audit and assessment programs, vendor and third-party risk management, security awareness training, governance metrics and reporting

## Key Learning Objectives

After studying this section, you should understand:

- The major regulatory frameworks and their scope of applicability
- Differences between SOC 2 Type I and Type II assessments
- ISO 27001 certification process and control families
- PCI DSS requirements for cardholder data environments
- GDPR data protection principles and breach notification obligations
- NIST CSF core functions (Identify, Protect, Detect, Respond, Recover)
- How to structure security policies, standards, and procedures
- Vendor risk management and third-party assessment approaches
- Audit program design and evidence collection
- Governance metrics for reporting to leadership

!!! info "Prerequisites"
    No specific technical prerequisites. Familiarity with basic security concepts is helpful. For foundational reading, refer to the [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) and [ISO 27001 Overview](https://www.iso.org/isoiec-27001-information-security.html).
