# Detection & Monitoring

This section covers detection systems, monitoring architecture, and the operational practices needed to identify and respond to security threats in real time. Detection engineering is the bridge between threat intelligence and incident response.

## Core Topics

- **[Detection Systems](detection-systems.md)** - Intrusion detection and prevention systems (IDS/IPS), signature-based vs behavior-based detection, rule writing (Snort, Suricata, YARA), honeypots and canary tokens, indicators of compromise, detection strategy design
- **[Monitoring & Analysis](monitoring.md)** - SIEM architecture and tooling, log sources and collection, alert triage and fatigue reduction, anomaly detection, network traffic analysis, security metrics and KPIs

## Key Learning Objectives

After studying this section, you should understand:

- IDS vs IPS deployment models and their trade-offs
- Signature-based and behavior-based detection mechanisms
- How to write detection rules in Snort, Suricata, and YARA
- Honeypot and canary token deployment strategies
- SIEM architecture, log aggregation, and correlation
- Common log sources and their security value
- Alert triage workflows and methods for reducing alert fatigue
- Network traffic analysis techniques for threat detection
- Security metrics and KPIs for measuring detection effectiveness

!!! info "Prerequisites"
    Understanding of networking fundamentals and common attack patterns is assumed. For background, refer to the [NIST Guide to Intrusion Detection and Prevention Systems](https://csrc.nist.gov/publications/detail/sp/800-94/final) and the [Elastic Security Guide](https://www.elastic.co/guide/en/security/current/index.html).
