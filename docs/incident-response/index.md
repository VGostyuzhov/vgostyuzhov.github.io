# Incident Response

This section covers incident management processes, from initial classification through containment, eradication, recovery, and post-incident review. Effective incident response requires clear roles, rehearsed procedures, and measurable outcomes.

## Core Topics

- **[Incident Management](management.md)** - Incident classification (security vs privacy), response models (PICERL, IMAG), roles and communication, investigation process, containment and eradication, recovery and lessons learned, metrics and prioritisation

## Key Learning Objectives

After studying this section, you should understand:

- Incident classification schemes and severity levels
- PICERL and IMAG response models and their phases
- Incident response team roles and communication protocols
- Investigation techniques for scoping and root cause analysis
- Containment strategies and their trade-offs
- Eradication and recovery procedures
- Post-incident review processes and documentation
- Key metrics (MTTD, MTTR, MTTC) and how to improve them
- The relationship between incident response and forensics

!!! info "Prerequisites"
    Familiarity with security operations and basic forensic concepts is assumed. For foundational reading, refer to [NIST SP 800-61: Computer Security Incident Handling Guide](https://csrc.nist.gov/publications/detail/sp/800-61/rev-2/final) and [SANS Incident Handler's Handbook](https://www.sans.org/white-papers/33901/).
