# Digital Forensics

This section covers forensic fundamentals - evidence handling, chain of custody, imaging - and the specialist disciplines of network, disk, memory, mobile, and cloud forensics.

## Core Topics

- **[Forensic Fundamentals](fundamentals.md)** - Evidence volatility and order of collection, chain of custody, forensic imaging and preservation, anti-forensics techniques, legal considerations
- **[Forensic Disciplines](disciplines.md)** - Network forensics (DNS logs, NetFlow, packet capture), disk forensics (imaging, filesystems, data carving), memory forensics (acquisition, structures, Volatility), mobile forensics, cloud forensics, tool reference

## Key Learning Objectives

After studying this section, you should understand:

- The order of volatility and why collection sequence matters
- Chain of custody requirements and documentation standards
- Forensic imaging techniques and write-blocking
- Common anti-forensics methods and how to detect them
- Network forensic analysis using packet captures and flow data
- Disk forensic workflows including filesystem analysis and data carving
- Memory forensic acquisition and analysis with tools like Volatility
- Differences between mobile, cloud, and traditional forensics
- Legal considerations for evidence handling and admissibility

!!! info "Prerequisites"
    Basic understanding of operating systems, filesystems, and networking is assumed. For foundational reading, refer to [NIST SP 800-86: Guide to Integrating Forensic Techniques](https://csrc.nist.gov/publications/detail/sp/800-86/final) and [SANS Digital Forensics](https://www.sans.org/digital-forensics-incident-response/).
