# Networking & Protocols

This section covers core networking concepts, protocols, security tools, and network-layer attacks relevant to infrastructure and cloud security engineering.

## Core Networking & Architecture

- **[Core Networking](core-networking.md)** - OSI model, TCP/IP stack, IP addressing, subnetting, routing, NAT, DHCP, and common service ports
- **[DNS](dns.md)** - Domain Name System architecture, record types, resolution process, and DNS-based attacks

## Protocols

- **[Network Protocols](protocols.md)** - Transport and application layer protocols including email (SMTP, IMAP, POP3), file transfer (FTP, SFTP), remote access (SSH, Telnet, RDP), and SSL/TLS

## Security

- **[Network Security & Tools](security-tools.md)** - Packet capture, network scanning, traffic monitoring, VPN/tunneling, proxy tools, and wireless security
- **[Network Attacks](attacks.md)** - Person-in-the-middle attacks, ARP spoofing, DNS attacks, BGP hijacking, DDoS, and CAM table overflow

## Key Learning Objectives

After studying this section, you should understand:

- The OSI model and how data traverses network layers
- TCP vs UDP characteristics and security implications
- How DNS works and common DNS attack vectors
- SSL/TLS handshake and certificate validation
- Common network protocols and their default ports
- Network scanning and packet analysis techniques
- Network-layer attack methods and their mitigations

!!! info "Prerequisites"
    Basic understanding of IP networking is assumed. For fundamentals, refer to the [Cisco Networking Basics](https://www.cisco.com/c/en/us/solutions/small-business/resource-center/networking/networking-basics.html) and [Computer Networking: A Top-Down Approach](https://gaia.cs.umass.edu/kurose_ross/index.php).
